# BeeBook – Privacy Policy

**Last updated: September 25, 2026**

BeeBook – Beekeeping Journal respects your privacy. This Privacy Policy explains how information is handled when you use the BeeBook mobile application.

## Information and Data

BeeBook allows users to record and manage information related to their beekeeping activities, including apiaries, hives, inspections, tasks, production, inventory, financial records, notes and other beekeeping information.

BeeBook does not require users to create an account to use the application.

The beekeeping records entered into BeeBook are stored locally on the user's device.

## Backup and Restore

BeeBook provides backup and restore functionality that allows users to create backup files containing their BeeBook data.

The user controls where these backup files are stored and whether they are shared or transferred.

## Photos and Camera

BeeBook may request access to the device's camera or photo library when the user chooses to use features that require images.

Access is used only when initiated by the user and is subject to the permissions provided through iOS.

## Data Sharing

BeeBook does not sell users' personal information.

BeeBook does not use users' beekeeping records for advertising or tracking.

## Data Retention and Deletion

Data stored locally by BeeBook remains on the user's device until it is deleted by the user or the application is removed.

Users can manage or delete records within the application.

Backup files created by the user remain under the user's control and can be deleted from their chosen storage location.

## Third-Party Services

If third-party services are introduced in future versions of BeeBook, this Privacy Policy will be updated to describe the relevant data practices.

## Changes to This Privacy Policy

This Privacy Policy may be updated when BeeBook features or data practices change. The latest version will be published on this page.
